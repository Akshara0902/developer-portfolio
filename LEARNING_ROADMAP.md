# Learning Roadmap

My 6-semester plan for BCA (AI & Data Science), 2026-2029.

| Semester | Focus | Goals |
|----------|-------|-------|
| 1 | Foundations | Linux shell scripting, Git/GitHub workflows, Python basics, Markdown documentation |
| 2 | Programming and Databases | Intermediate Python, data structures basics, SQL and database fundamentals |
| 3 | Data Analysis | NumPy, Pandas, data cleaning, data visualisation, statistics for data science |
| 4 | Machine Learning | Supervised and unsupervised learning, scikit-learn, model evaluation, REST APIs |
| 5 | Applied AI | Deep learning basics, NLP or computer vision, mini projects, internship preparation |
| 6 | Capstone and Career | Capstone project, model deployment, portfolio polish, placement preparation |

## Ongoing Habits

- Commit work to GitHub regularly with clear commit messages
- Practise problem solving in Python each week
- Update this roadmap at the end of every semester
